# Night Shift

A rooftop courier platformer for **GitHub Game Off 2026** (theme: **SHIFT**).
Press **SHIFT** to swap which neon platforms are solid, dodge the drone, and make your delivery.

**Play in your browser:** https://oharedanny340-bot.github.io/night-shift/

## Controls
- Arrow keys / A-D: move
- Up / W / Space: jump
- SHIFT (or X): swap blue and pink platforms
- R: restart

## About
Made by Danny O'Hare with Phaser 3, plain JavaScript and no build tools.
AI agents (Claude) helped design, write and code this game.
